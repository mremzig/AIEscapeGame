# AIEscapeGame

> Bu proje, mülakat kapsamında geliştirilmiş bir mini projedir.
> Güvenlik kaygıları nedeniyle .exe paketi eklenmemiştir. Projeyi çalıştırmak için UE5.7.4 gereklidir.

## Proje Hakkında

Unreal Engine 5.7.4 ile geliştirilmiş olan bu proje, Blueprint tabanlı üçüncü şahıs bir kaçış oyunudur.

## Oyun Özellikleri

- AI takip sistemi
- Anahtar ile kapı açma mekaniği
- Ölüm ve yeniden başlama ekranı
- Başlangıç menüsü

## Kontroller
| Tuş | İşlev |
|-----|-------|
| WASD | Hareket |
| E | Etkileşim |
| Mouse | Kamera |

## Kullanılan Teknolojiler

- Unreal Engine 5.7.4
- Blueprint Visual Scripting
- Pawn Sensing
- Blueprint Interface (BPI)


## Bilinen Sorunlar

- Kapı görseli temel bir model ile oluşturulmuştur.
- UI tasarımı işlevsellik öncelikli tutulmuş, görsel detaylar sınırlı kalmıştır.
